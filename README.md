# Girly City

The girly GTA: a pastel Vice Beach where you do iced coffee runs, nail appointments, shopping sprees, brunch with the girls and a golden-hour photo shoot for your bestie, while a "Drama" meter fills if you are late or make bad choices.

- Stack: Vite + Three.js, single-player, static site (Vercel).
- Dev: `npm install && npm run dev`
- Build: `npm run build` → `dist/`
